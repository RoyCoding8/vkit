# Integer loop termination

`analyze_loop_termination(root, path, function, timeout_seconds=10)` captures one Python source file and models the selected function without importing or executing it. The function needs one to four positional `int` parameters, an `int` return annotation, one `while` loop, and one final integer return. Its body may assign to existing parameters with total piecewise-affine integer expressions. Assignments follow Python's sequential evaluation order. Calls, effects, nested loops, early exits, multiplication of variables, defaults, decorators and unsupported syntax are rejected.

The service uses pinned cvc5 1.4.2 to synthesize an integer ranking `offset + sum(coefficient[name] * state[name])`. Candidate coefficients range from -16 to 16 and the offset from -2^32 to 2^32. Each candidate is checked against every guarded transition over mathematical integers. `TERMINATES` requires an unsatisfiable query for either a negative current ranking or a non-decreasing next ranking. The result includes the checked ranking. If the initial guard holds, the number of loop transitions is at most `ranking(initial_state) + 1`; otherwise it is zero. The extra transition allows a final guarded state with ranking zero to exit the loop.

`NONTERMINATING` requires a concrete guarded fixed point whose update is independently replayed through the installed integer expression evaluator. It proves there is an initial state that repeats forever in the supplied model. Other forms of nontermination, including longer cycles, may return `UNKNOWN`. A failed candidate search never establishes nontermination. Counterexamples used to refine the ranking search are independently replayed before constraints are added.

The synthesis search is bounded to 48 candidates. It is incomplete. The verification of a returned ranking covers the entire supported integer state domain. The parent process enforces a 1–60 second wall deadline around the trusted worker; solver queries share that worker's remaining deadline. Source is limited to 64 KiB, 1,000 AST nodes and depth 64; expanded update expressions are limited to 1,000 nodes and integer constants to 256 bits. This worker does not provide an OS memory sandbox. Missing or mismatched cvc5 returns `UNAVAILABLE`; unsupported source returns `UNSUPPORTED`; timeout, failed replay and exhausted synthesis return `UNKNOWN`.

This is a loop-model proof. It does not prove application termination, finite-machine behavior, freedom from resource exhaustion, or correctness of ignored module-level code. The ranking obligation follows the established [linear ranking function approach](https://doi.org/10.1007/978-3-540-24622-0_20); the bounded counterexample-guided synthesis used here does not claim that paper's completeness.
